# MHXX お守り乱数計算機 (Android版)

モンスターハンターダブルクロスの「お守り」の乱数を、既存の解析ロジック
(ノートブック由来、`mhxx_rng.py`) をもとに検索・予測するための、
スマホで使える純粋な計算ツールです。

**このアプリが行うこと**: フレーム番号やスキル条件から、狙ったお守りが
出るフレームを計算する — それだけです。Switch本体やゲームプロセスへの
自動入力・自動操作・通信は一切行いません(必要な数値は自分の目で見て
手入力する前提の、電卓のようなツールです)。

## 機能

| タブ | 内容 |
|---|---|
| 🔍 検索 | スキル/スロット条件を指定してフレームを検索 (完全一致 / 以上) |
| 📋 周辺確認 | 指定フレーム前後のお守りを一覧表示 |
| 🧪 調合スナイプ | 調合の「累計作成数」列から現在フレームを特定 |
| 🎯 狙い目 | クエスト/マカフシギ/天運の有効フレームを計算 |

検索結果のカードをタップすると、そのフレームを周辺確認タブに渡して
自動表示します。

## セットアップ (GitHub Actionsで APK をビルド)

1. GitHubで新しいリポジトリを作成します (Public / Private どちらでも可)。
2. このフォルダの中身をそのリポジトリに push します。

   ```bash
   cd mhxx_rng_app
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/<あなたのユーザー名>/<リポジトリ名>.git
   git push -u origin main
   ```

3. push すると `.github/workflows/build-apk.yml` が自動的に動き、
   Buildozer で APK をビルドします。GitHubの対象リポジトリで
   **Actions** タブを開くと進行状況が確認できます。
   (手動で再実行したい場合は Actions タブ →
   「Build APK」→ **Run workflow** でも起動できます)
4. ビルドが終わったら、そのワークフロー実行画面の一番下
   **Artifacts** から `mhxx-rng-tool-apk` をダウンロードします
   (zipでダウンロードされるので展開すると `.apk` が入っています)。
5. スマホにその `.apk` を転送し、タップしてインストールします。
   初回は「提供元不明のアプリ」の許可を求められることがあります。

### 注意

- **初回ビルドは20〜40分程度かかります** (Android SDK/NDKを
  ダウンロードするため)。2回目以降はキャッシュが効いて
  短縮されます。
- これは個人利用向けのツールとして構成しています。Google Play
  で公開する場合は `buildozer.spec` の `package.domain` を
  実際に所有するドメインの逆順にするなど、別途調整が必要です。
- 「検索」を大きいステップ数 (数千万〜) で実行すると、端末や
  他の作業状況によっては「停止」を押してから実際に止まるまで
  数秒かかることがあります (バックグラウンドスレッドが現在の
  処理を終えてから停止するため)。

## PCでの動作確認 (APKビルド前のプレビュー用・任意)

Android実機にインストールする前に、PC上のKivyで見た目を
確認することもできます。

```bash
pip install kivy
python main.py
```

## 技術的な補足

- `mhxx_rng.py` は元のデスクトップ版ツールのロジックを**一切変更せず
  そのまま**使用しています。乱数アルゴリズム・テーブル・しきい値の
  正しさは元のロジックにそのまま依存します。
- 日本語表示のため [Noto Sans JP](https://github.com/notofonts/noto-cjk)
  (SIL Open Font License 1.1) を同梱しています。ライセンス全文は
  `assets/fonts/LICENSE-NotoSansJP.txt` を参照してください。
- UIはタッチ操作向けに新規に作成したものです (Kivy)。検索は
  バックグラウンドスレッドで実行し、進捗表示・途中停止に対応して
  います。
